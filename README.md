# Zepto Product Catalog & Analytics Pipeline

## Project Overview
An end-to-end data engineering and analytics solution for quick-commerce product catalogs. This project scrapes product details, stores them in a structured SQLite database, and provides analytical insights.

## Project Structure
- `data_pipeline/`: Scraper scripts, database setup, and SQLite database storage.
- `requirements.txt`: Python package dependencies.

## Module 1: Data Pipeline Execution
1. Install dependencies:
pip install -r requirements.txt
2. Run data extraction and storage:
```bash
python data_pipeline/main.py
